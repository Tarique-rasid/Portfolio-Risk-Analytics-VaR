# Portfolio-Risk-Analytics-VaR
Python-based portfolio risk analytics framework implementing Historical VaR, Parametric VaR, Monte Carlo VaR, Expected Shortfall, and VaR Backtesting.
# Portfolio Risk Analytics & Value at Risk (VaR) Model

## Overview

This project analyzes the market risk of a diversified Indian equity portfolio consisting of:

- Reliance Industries
- TCS
- HDFC Bank
- Infosys

Using historical market data, the project implements multiple risk management techniques commonly used in banking and financial institutions.

## Methodologies

- Historical VaR
- Parametric VaR
- Monte Carlo VaR
- Expected Shortfall (CVaR)
- VaR Backtesting
- Sharpe Ratio Analysis

## Results

| Metric | Value |
|----------|----------|
| Historical VaR | ₹1,651.95 |
| Parametric VaR | ₹1,613.16 |
| Monte Carlo VaR | ₹1,634.57 |
| Expected Shortfall | ₹2,224.41 |
| Annual Return | 10.22% |
| Annual Volatility | 15.96% |
| Sharpe Ratio | 0.26 |
| VaR Violation Rate | 5.02% |
